# b8k-ci

Общий выпуск репозиториев b8k (ADR 0002 в
[lenovo-b8000h-linux](https://github.com/trudenboy/lenovo-b8000h-linux)):
по тегу `vX.Y.Z` проверить, что версии в файлах совпадают с тегом, собрать и
подписать пакет Alpine 3.24 (`noarch` или `armv7`) и выложить его с
`SHA256SUMS` в GitHub Release.

- `.github/workflows/apk.yml` — переиспользуемый workflow (вызов — в его
  заголовке); нужен секрет `B8K_APK_PRIVKEY` (закрытый ключ проекта).
- `build-apk.sh` — сборка пакета в контейнере `alpine:3.24`; зависимости
  b8k — из их последних выпусков, остальное — из Alpine.
- `keys/` — открытый ключ, которым подписаны пакеты.

Политика версий — SemVer: X — несовместимые изменения (команды, форматы
файлов, ключи `X-B8K-…`, API `b8k-compat`), Y — новые возможности, Z —
исправления и изменения упаковки. Тег = `pkgver` = версия в metainfo и
`pyproject.toml`; `pkgrel` всегда 0.
